| 字段 | 内容 |
| --- | --- |
| 决策编号 | LUNE-DEC-009 |
| 决策日期 | 2026-10-30 |
| 决策背景 | QA-A03、安全 S-02 和 AI P-02 要求明确自动记忆、聊天纠错及删除后的恢复授权 |
| 问题描述 | 哪些内容可自动整理为共同记忆，如何反馈纠正和重新记住 |
| 备选方案 | 默认全量自动记忆；每条均需手工确认；有限自动采纳并保留用户控制。PM 推荐第三种 |
| 最终决定 | 普通、稳定、非敏感信息可自动整理成可查看、可纠错的记忆；敏感细节、临时情绪、玩笑和不确定推测不自动长期记住；聊天中收到纠正，当前回应立即尊重，实际保存成功才提示“已更新”；已删除信息只有用户明确要求重新记住时才能恢复 |
| 决策原因 | 发起人接受 PM 的整套记忆规则，在减少维护负担的同时保留掌控及真实反馈 |
| 可能影响 | 不能把口头接受纠正等同持久保存，也不能因旧聊天可见或再次谈及话题自动恢复已删除记忆；记忆采纳准确性、实际保存、纠错和恢复能力留待后续验证。本决定不自动批准 AI 全部冲突策略、敏感信息主动收录或新增设置开关 |
| 确认人及依据 | 项目发起人，本聊天在四条记忆规则建议后明确回复“接受” |
